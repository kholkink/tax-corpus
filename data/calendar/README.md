# Производственный календарь

Файлы `<год>.json` с переносами выходных по постановлениям Правительства РФ:

```json
{"source": "Постановление Правительства РФ от … № …", "holidays": ["2025-05-02", "2025-05-08"], "workdays": ["2025-11-01"]}
```

`holidays` — дополнительные нерабочие дни (перенесённые выходные), `workdays` — рабочие
субботы. Фиксированные праздники ст. 112 ТК РФ и субботы/воскресенья учитываются кодом.
Без файла за нужный год `compute_deadline` печатает предупреждение.
