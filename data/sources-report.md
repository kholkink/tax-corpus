## 3. Рабочий рецепт API ГАС «Законодательство России» (рекомендуемый основной путь)

Домен ГАС теперь живёт на **pravo-search.minjust.ru** (UI: `/bigs/portal.html`, JSON-API рядом).
Ограничения доступа: HTTPS-сертификат хоста **истёк** → curl с `-k`; nginx отдаёт 403 на `/bigs/content/...`
и `/bigs/openPresentation.action` (файловая выдача закрыта для анонимных); сессия заводится GET-ом
`portal.html` (cookie jar обязателен).

Документ НК ч.1 в банке: `id = F7DE1846-3C6A-47AB-B440-B8E4CEA90C68`, шард «Текущие редакции»,
текущая редакция **№199 от 04.08.2026**.

### 3.1 Поиск документа (UUID по названию/номеру)
```bash
curl -sk -c cookies.txt "https://pravo-search.minjust.ru/bigs/portal.html"        # сессия
sleep 2
curl -sk -b cookies.txt -X POST \
  -H "Content-Type: application/json; charset=utf-8" -H "X-Requested-With: XMLHttpRequest" \
  -H "Referer: https://pravo-search.minjust.ru/bigs/portal.html" \
  --data-binary @query.json "https://pravo-search.minjust.ru/bigs/s.action"
```
`query.json` — готовый запрос каталога «Кодексы Российской Федерации» (см. `data/raw/q_codes_full.json`):
```json
{"request": {"mode":"EXTENDED", "rows":30,
  "typeRequests":[{"name":"Правовые акты", "mode":"AND", "typesMode":null,
    "fieldRequestGroups":[{"mode":"AND","fieldRequests":[
      {"name":"document_description","operator":"EX","query":"КОДЕКС"}]}]}],
  "groups":["Текущие редакции"], "sortField":"document_date_edition","sortOrder":"asc",
  "additionalFields":["document_text","document_text_tag","document_edition","document_edition_link",
                      "document_number","document_date_edition","document_date_public"],
  "customFilters":[]}}
```
Каталоги банка — POST `{}` на `/bigs/getCatalogs.action` (разделы: Федеральное законодательство,
Кодексы РФ, Акты министерств и ведомств, акты субъектов РФ и др.).

### 3.2 Ключевые поля
- `document_text` — plain-текст; `document_text_tag` — размеченный HTML (инжестить этот);
- `document_edition` — «Редакция №199 от 04.08.2026» (номер/дата текущей редакции);
- `document_edition_link` — повторяющееся поле: `Редакция №N от DD.MM.YYYY___<UUID акта>___<UUID редакции>`;
- `document_number` (напр. «146-ФЗ»), `document_date_edition`, `document_date_public`.

## 4. Редакции на дату — итог

- Банк **хранит** консолидированные редакции на дату: для НК ч.1 выгружено 198 ссылок
  (№1 от 31.07.1998 → №198 от 04.08.2026; в банке их 199, текущая №199 лежит в шардe «Текущие редакции»
  как сам текст акта). Структура типа «Редакции актов» содержит поля `edition_text`, `edition_text_tag`,
  `edition_date_edition`, `edition_date_doc_edition` — т.е. текст каждой редакции есть в модели.
- **Открытая проблема:** вытянуть текст произвольной редакции через открытый JSON-поиск не удалось
  (запросы по типу `Редакции актов` дают 0 — нужен правильный шард/фильтр), а карточка документа
  `POST /bigs/showDocument.action` сломана на стороне сервера (Solr: `shardsWhitelist not configured`,
  ошибка воспроизводится и без параметра shard), файловые пути закрыты nginx-403.
- Практический вывод: текущая редакция (для инжеста корпуса) — доступна и скачана; исторические
  редакции на дату — с этой площадки пока нет, иначе чем через внутренние пути ГАС.

## 5. Запасные пути

1. **СОЗД (sozd.duma.gov.ru)** — поиск `https://sozd.duma.gov.ru/search?number=98000754-2` работает
   (сервер-рендер, есть `?print=1` → асинхронная выгрузка `{"path":"tmp_download_..."}`), но карточка
   `/{id}` для 98000754-2 даёт 404 (старый идентификатор), публичные REST-эндпоинты не найдены,
   файлы DOC/PDF лежат за карточкой законопроекта (в robots.txt `/download/` закрыт даже для ботов).
   Развивать при следующем боксе: найти URL карточки через UI-скрипты, список изменяющих законов
   собирать из карточек законов, принимающих поправки.
2. **publication.pravo.gov.ru** — официальный API `/api/documents/{дата публикации}/{номер}` для
   PDF/RTF оригинала и каждого изменяющего закона; из текущей сети недоступен (TLS/гео). Для
   применения патчей (реконструкция редакций) — запускать с российского IP.
3. **Реконструкция редакций патчами**: 146-ФЗ (оригинал) + цепочка изменяющих ФЗ. Официальные тексты
   изменяющих законов — там же в ГАС (каждый изменяющий ФЗ — отдельный документ банка с полным текстом),
   либо publication.pravo.gov.ru. Список изменяющих ФЗ частично восстанавливается из дат редакций
   (`minjust_GAS-Zakonodatelstvo_NK-RF-ch1_editions-list.json`).

## 6. Ограничения / лицензионные замечания

- **Только официальные источники** — соблюдено (Минюст/Госдума; коммерческие агрегаторы не использовались).
- **robots.txt**: у sozd.duma.gov.ru `Disallow: /` для всех UAs кроме Яндекса/Google — сделано лишь
  несколько точечных запросов (страница поиска, 3-4 пробы API), без обхода страниц. У ГАС
  (pravo-search.minjust.ru) robots.txt не обнаружен; браузерообразные заголовки.
- **Частота**: пауза ≥2 с между запросами ко всем хостам.
- **TLS**: сертификат pravo-search.minjust.ru просрочен — запросы шли с `-k` (контент не подменялся,
  но канал не верифицирован; зафиксировать в реестре рисков).
- Лицензия: тексты законов РФ — государственные информационные ресурсы, официальное опубликование
  обязательно и общедоступно; на банке ГАС отдельной лицензии/регистрации не требуется (анонимный доступ),
  регистрация не нужна. Ограничений на скачивание текста не обнаружено (файловая выдача закрыта технически,
  но не юридически — точные условия не найдены, уточнить на `pravo.minjust.ru/about_project`).
- Ничего не устанавливалось; использовались curl + предустановленный python.

## 7. Рекомендуемый путь инжеста

1. **Основной**: ГАС `pravo-search.minjust.ru/bigs/s.action` (JSON-поиск с `additionalFields`) —
   официально поддерживаемый банк Минюста, отдаёт и HTML (`document_text_tag`), и plain-текст, и
   номер/дату текущей редакции, и полный список редакций. Работает из текущей сети (только HTTP+cookie+`-k`).
2. **Запасной для текущих текстов**: повторение того же запроса по другим документам банка (все кодексы —
   одним запросом, проверено: ответ 26 документов ~30 МБ).
3. **Для исторических редакций / верификации**: publication.pravo.gov.ru (с российского IP) или СОЗД;
   самостоятельный патч-применитель по цепочке изменяющих ФЗ.
